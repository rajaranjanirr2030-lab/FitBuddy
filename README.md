# FitBuddy – AI-Based Personalized Fitness Assistant

## Project Overview

FitBuddy is an AI-based personalized fitness assistant that helps users generate customized workout plans and receive nutrition guidance based on their fitness goals and preferences.

## Problem Statement

Creating a suitable fitness plan can be difficult for users because workout and nutrition needs differ from person to person. FitBuddy aims to provide personalized fitness assistance using Generative AI.

## Key Features

* Personalized 7-day workout plan generation
* Nutrition tips based on user requirements
* Workout plan updates based on user feedback
* AI-powered fitness assistance
* Simple and user-friendly interface

## Technologies Used

* Python
* FastAPI
* HTML
* CSS
* JavaScript
* Generative AI / Gemini API
