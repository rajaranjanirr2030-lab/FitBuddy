# Phase 3: App Development

## Objective

Develop the main application for FitBuddy using Python and FastAPI.

## Technologies Used

* Python
* FastAPI
* Google Gemini API
* Jinja2 Templates
* HTML
* CSS
* JavaScript

## Implementation

The FitBuddy application was developed using FastAPI as the backend framework. The application accepts user details such as name, age, weight, fitness goal, and workout intensity.

The backend processes the user input and uses the Gemini AI model to generate a structured 7-day workout plan.

## Main Features

* User input form
* Workout plan generation
* AI-powered workout recommendations
* Workout plan updating based on user feedback
* Nutrition tips
* FastAPI backend integration
* Web-based user interface

## API Integration

Google Gemini API is integrated into the application to generate personalized workout plans and provide AI-based responses.

## Expected Result

The application successfully receives user information, processes the request, generates an AI-based workout plan, and displays the result to the user.
