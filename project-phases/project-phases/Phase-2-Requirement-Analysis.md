Phase 2 — Requirement Analysis
Functional Requirements
User should enter personal information.
User should provide fitness goal.
User should select workout intensity.
System should generate a personalized workout plan.
System should provide nutrition tips.
System should be able to update the workout plan based on feedback.
System should display the generated response clearly.
System should handle AI/API errors.
User Inputs
Name
User ID
Age
Weight
Fitness goal
Intensity
Expected Output

A structured personalized workout plan, organized for the required period, along with relevant guidance.

Non-Functional Requirements
Easy-to-use interface
Fast response where possible
Clear output
Error handling
Maintainable code
